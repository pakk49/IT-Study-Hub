## วิธีใช้งาน

1. เลือก **ชั้นปี → เทอม → วิชา → บทเรียน**
2. เปิดแท็บ **สรุปบทเรียน** เพื่ออ่านแยกหัวข้อ และทำเครื่องหมายว่าอ่านแล้ว
3. เปิด **Flashcards** ลองตอบก่อนแตะเปิดเฉลย ใช้ปุ่มก่อนหน้า / ถัดไป หรือสลับการ์ด
4. เปิด **ลองทำข้อสอบ** แล้วเลือกคำตอบก่อนกดตรวจ
5. ระบบแสดงคำตอบที่ถูก เหตุผลที่คำตอบของคุณผิด และเหตุผลของทุกตัวเลือก
6. เมื่อครบชุด จะแสดงคะแนนและให้ฝึกเฉพาะข้อที่ผิด หรือเริ่มชุดเต็มใหม่ได้

**ธีม: ฟ้าอ่อน–น้ำเงินอ่อน ตัดด้วยสีส้มอุ่น**

**สิ่งที่มีให้ใช้**

- ค้นหาด้วยชื่อวิชา รหัสวิชา ชื่อบท หรือคำศัพท์ในสรุป
- ลิงก์ตรงแต่ละวิชา / บท / แท็บ เปิดใหม่หรือแชร์ได้โดยไม่เกิด 404 จากเส้นทาง
- บันทึกสถานะอ่านแล้วและคะแนนสูงสุดของชุดเต็มด้วย `localStorage`
- รอบฝึกข้อผิดไม่เขียนทับคะแนนสูงสุดของชุดเต็ม
- รองรับมือถือ คีย์บอร์ด และการพิมพ์สรุปด้วย `Ctrl + P`
- ถ้าไม่อนุญาตให้ใช้ Storage ยังอ่านและทำข้อสอบได้ แต่ไม่เก็บความคืบหน้าข้ามรอบ

> ความคืบหน้าเก็บในเบราว์เซอร์ของแต่ละเครื่อง ไม่มีระบบบัญชีหรือการซิงก์ข้ามอุปกรณ์ ข้อสอบเป็นแบบฝึกหัดที่เรียบเรียงจากบทเรียน ไม่ใช่ข้อสอบจริงของรายวิชา

## เพิ่มเนื้อหา

ข้อมูลอยู่ใน [`assets/content.js`](assets/content.js) แยกจากระบบหน้าเว็บ

<details>
<summary><b>เพิ่มวิชาหรือบทใหม่อย่างไร?</b></summary>

แต่ละวิชาใช้โครงสร้าง:

```js
{
  id: 'subject-slug', // ไม่ซ้ำ ใช้ใน URL
  code: '00000000',
  title: 'SUBJECT NAME',
  thai: 'ชื่อวิชา',
  year: 2,
  term: 1,
  label: 'XX',
  description: 'คำอธิบายวิชา',
  chapters: []
}
```

เพิ่มบทใน `chapters` โดยใช้บท 6 เป็นตัวอย่าง:

- `id` ต้องไม่ซ้ำทุกบทในระบบ เพราะใช้เป็น key เก็บความคืบหน้า
- `number`, `title`, `description`, `minutes`, `source` เป็นข้อมูลบท
- `sections` มี `id`, `title`, `pages`, `intro`, `points`, `remember` และเพิ่ม `table` / `formula` ได้
- `flashcards` มี `id`, `front`, `back`
- `questions` มี `id`, `topic`, `level`, `prompt`, `options`, `answer`, `reasons`
- `topic` ต้องตรงกับ `id` ของ section เพื่อให้ย้อนอ่านหัวข้อได้
- `options` และ `reasons` ต้องมี 4 รายการ; `answer` คือ index 0–3 ของคำตอบที่ถูก
- ข้อสอบต้องมีคำตอบที่ถูกเพียงข้อเดียว พร้อมเหตุผลตรงกับตัวเลือก
- รักษาศัพท์เฉพาะภาษาอังกฤษตามต้นฉบับ และระบุแหล่งเนื้อหา

</details>

## ตั้งค่าเว็บ

เว็บเป็น **Static HTML + CSS + JavaScript Modules** ไม่มี backend และไม่ต้องติดตั้ง dependency เพื่อเปิดใช้

### GitHub Pages

1. เข้า **Settings → Pages** ของ repo
2. ใน **Build and deployment → Source** เลือก **GitHub Actions**
3. Workflow [Deploy study hub to GitHub Pages](.github/workflows/pages.yml) จะตรวจข้อมูลและ deploy เมื่อ push เข้า `main`
4. ถ้าเพิ่งเปลี่ยน Source ให้ไป **Actions → Deploy study hub to GitHub Pages → Run workflow**
5. เมื่อ workflow สำเร็จ เปิด https://pakk49.github.io/IT-Study-Hub/

ชื่อโดเมนสำหรับเว็บนี้คือ `github.io` ไม่ใช่ `git.io`

### เปิดบนเครื่อง

```bash
python -m http.server 8000
```

เปิด `http://localhost:8000` ผ่าน HTTP เพราะ JavaScript Modules อาจไม่ทำงานเมื่อดับเบิลคลิกเปิดแบบ `file://`

### ตรวจสอบก่อนอัปเดต

ต้องมี Node.js 22 ขึ้นไป แล้วรัน:

```bash
npm test
```

ทดสอบข้อมูลวิชาและบท จำนวนตัวเลือก เหตุผล ลิงก์หัวข้อ การตรวจคะแนน การสลับข้อ สูตรตัวอย่าง และการเก็บความคืบหน้า
